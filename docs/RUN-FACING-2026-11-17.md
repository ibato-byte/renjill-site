# 進む方を向いて走る（レンとジルの移動）　2026-11-17

オーナー：「左に行く時はちゃんと左に向いて走るように、現実に近い最高のアニメーションとするためのブラッシュアップを追加で 50 以上。様々な角度で」

## 原因
2 人の絵は斜め前から見た形で、レンは右・ジルは左を向いている（ふだんは向かい合う）。移動の時は、向きを少し回すだけだったので、
レンが左へ行く時・ジルが右へ行く時は、お尻を先にして走っていた（頭がうしろ）。

## 撮り方
tools/film_move.mjs：1 回の移動を 33ms ごとに撮る。ページの時計を自分で進めるので、撮るのに時間がかかっても動きがとばない
（前の撮り方では、1 枚撮る間に 0.3 秒進んでしまい、走りの途中が写らなかった）。左・右、PC（1280）・スマホ（390）で撮って確かめた。

## 向きを変える動きを、自然に作り直した（オーナー 11-17：「レンが瞬間的に向きを変えるのが物理的に違和感がある」）
前は、絵を 0.13 秒で左右に裏返すだけだった（回っていない）。
- 体を縦の軸で本当に回す（光の当たり方も一緒に回る）
- 回すのは 40 度まで（真横まで回すと、ふくらみの絵が流れて乱れた。撮って確かめた）
- 小さく跳ねた一番上で左右を入れかえ、反対側から回しもどす（手描きのアニメと同じやり方）
- ゆっくり始まり、ゆっくり終わる。重いレンは 0.45 秒、小さいジルは 0.32 秒
- 向きを変え終わる少し前から、跳ぶ準備に入る
