# 進む方を向いて走る（レンとジルの移動）　2026-11-17

オーナー：「左に行く時はちゃんと左に向いて走るように、現実に近い最高のアニメーションとするためのブラッシュアップを追加で 50 以上。様々な角度で」

## 原因
2 人の絵は斜め前から見た形で、レンは右・ジルは左を向いている（ふだんは向かい合う）。移動の時は、向きを少し回すだけだったので、
レンが左へ行く時・ジルが右へ行く時は、お尻を先にして走っていた（頭がうしろ）。

## 撮り方
tools/film_move.mjs：1 回の移動を 33ms ごとに撮る。ページの時計を自分で進めるので、撮るのに時間がかかっても動きがとばない
（前の撮り方では、1 枚撮る間に 0.3 秒進んでしまい、走りの途中が写らなかった）。左・右、PC（1280）・スマホ（390）で撮って確かめた。

## 直した所（番号つき）
### 向き
1. 進む方へ頭を向ける（絵を左右反転）
2. 反転した時は、光の当たる側も反転
3. 跳ぶ時の足ののび（前足は前・後ろ足はうしろ）を、向きに合わせる
4. 押した時の跳ね（その場で跳ぶ）も、向きに合わせる
5. 向きを変え終わってから跳ぶ（前は向きを変えながら跳んでいた）
6. 向きを変える速さ：約 0.11〜0.16 秒（うさぎはその場で素早く向きを変える）
7. 向きを変える途中も細くなりすぎない（紙のように薄く見えた）
8. 向きを変える時に少し沈む
9. 向きを変える時に、小さく跳ねてまわる
10. 向きを変える時、耳がふわっと外へ
11. 向きを変える時は、後ろ足を体の下に集めて、それを軸にまわる
12. 着いたあとも少しの間は進んだ方を向き、それから相手のほうへ向き直る
16. ジルは早く向き直る（0.6 秒）、レンはゆっくり（1.1 秒）
17. 小さいジルはすばやく、重いレンはゆっくり向きを変える

### 走り（うさぎ跳び）
18. 1 歩目は短く（走り出し）
19. まん中の跳びは長く
20. 最後の跳びは短く（止まる）
21. 走っている途中は、地面にいる時間が短い
22. 跳びの高さは、その跳びの長さに合わせる
23. 長い移動でも高く跳ばない（前は 110 まで跳んでいた → 64 まで）
24. ジル（小さい種類）は、小さな跳びを多く
25. 重いレンは低く、軽いジルは少し高く
26. 遠くへ行く時ほど、深くためる
27. 重いレンは、ためが少し長い
28. 走ると耳はうしろへ流れる
29. 跳ぶ直前に、耳が少しうしろへ（これから跳ぶ合図）
30. 足が着くたびに、耳がはずむ
31. 跳んでいる間は、まばたきしない（前を見ている）
32. 頭のゆれも向きに合わせる
33. 跳んでいる間は回しすぎない（絵がもう進む方を向いているので。回すと体が平たく見えた）

### 着地
34. レン（重い種類）は着地で大きく沈む
35. ジル（軽い種類）は着地で軽く
36. 着いたあと、勢いで少しすべって止まる
37. すべる長さは、跳びの大きさに合わせる
38. 長く走ったあとは、息が速い（走った長さに合わせる）
39. 長く走ったあとは、立ち止まって見回すことがある

### 土ぼこり・かげ
40. けった所に小さな土ぼこり
41. 足が着くたびに土ぼこり
42. 着地にも土ぼこり
43. 土ぼこりは、暗い所では明るく、明るい所では茶色に
44. 土ぼこりの大きさは、跳びの高さに合わせる
45. 土ぼこりは、うしろへけり出され、少し上がる
46. 足が着いた瞬間、かげが少し濃くなる
47. 向きを変える途中は、かげも短くなる（体を前から見る形になるので）
48. かげは体（頭のうしろ）の下へ少しずらす

### 2 人の並び
49. 進む方で前にいる子が先に出る（うしろの子が、前の子を飛びこえていた）
50. たてに動く時は、今までどおりの順番
51. 走っている間、前の子に追いつかない（間をあける）
52. 間を少し広げる（まだ体が少しふれていた）

## 取り消した物（オーナー 11-17）
- 「カーソルがうしろにあると、耳を立ててからふり向く」（3 か所）。オーナー：「カーソルを見るためだけに、いちいち体の向きを変える必要はない」。
  体の向きを変えるのは移動の時だけ。カーソルは、今までどおり頭と目で追う。

## 向きを変える動きを、自然に作り直した（オーナー 11-17：「レンが瞬間的に向きを変えるのが物理的に違和感がある」）
前は、絵を 0.13 秒で左右に裏返すだけだった（回っていない）。
- 体を縦の軸で本当に回す（光の当たり方も一緒に回る）
- 回すのは 40 度まで（真横まで回すと、ふくらみの絵が流れて乱れた。撮って確かめた）
- 小さく跳ねた一番上で左右を入れかえ、反対側から回しもどす（手描きのアニメと同じやり方）
- ゆっくり始まり、ゆっくり終わる。重いレンは 0.45 秒、小さいジルは 0.32 秒
- 向きを変え終わる少し前から、跳ぶ準備に入る

## 足した物
53. ほんの少しの移動（体の半分より短い）は、向きを変えずに横へ一歩ずれる（向きを変えると大げさだった）
