# 本物のうさぎらしさ（全体）の作り込み（2026-11-18）

研究メモ（project「うさぎの動きの研究と作り込み」）の「分かったこと」と照らして、まだ入っていなかったものを足す。

1. 伸びた後に、ぷるっと身ぶるいする（6 割。研究メモの「のびた後、ぷるっと身ぶるい」）
2. 寝ている間は、鼻のひくひくがゆっくり（起きている時 約 5.8 回／秒 → 寝ている時 2 回／秒）
3. 眠りに落ちる前の 1.4 秒、頭がこくりと下がっていく（うとうと）
4. 起きた時、伸び（あくび）が終わってから、目を 2 回しばたたく

確かめ：ページの時計を自分で進め、数字（鼻の回数・頭の高さ・顔・していること）を記録。
5. 長く座っている時、ときどき重心を左右へ移す（約 20 秒ごとに、体の傾きが少し変わる。傾きの幅 0.014 → 0.026）
- 試してやめた案：となりが寝ている時に見守る（この場面では、もともととなりの方を向いていて、違いが出なかった）
6. 新しい場所に着いたら、まず頭を下げて床のにおいをかぐ（0.9 秒。鼻のひくひくも）
7. 毛づくろいの後半（1.3 秒後から）は、ジルが耳を前足で引き下ろして洗う
- 試してやめた案：警戒した時にレンのたれ耳の付け根を持ち上げる（試した場面でレンが寝転んでいて、効果を確かめられなかった）
