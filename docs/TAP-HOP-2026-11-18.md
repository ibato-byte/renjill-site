# 押した時の跳ね方（2026-11-18）

前から残っていた「押すと、頭が体に沈んで見えるコマがある」を、1 コマずつ撮って直した。

## 原因
- 寝ているレンを押すと、目がさめた時の「伸び」が、跳ぶのと同時に始まっていた。空中で伸びの絵（頭を下げて前足をのばす姿）に切りかわり、頭が沈んで見えた。
- 上へ跳ぶ速さに合わせて、頭を下へ押しつぶすゆがみがかかっていた（本物は跳んでも頭はつぶれない）。

## 直した所
1. 伸びの絵は、床にいる時だけ（空中では切りかえない）
2. 押されて起きた時の伸びは、着地して落ち着いてから始める
3. 空中では頭を押しつぶさず、速さに合わせて少しだけ縦にのびる
4. 空中では体をわずかに縦にのばす（つぶれるのは着地の時だけ）

確かめ：レン・ジルそれぞれ、押した直後を 33ms ごとに 40 コマ撮って見た。点検 57 項目すべて合格。
