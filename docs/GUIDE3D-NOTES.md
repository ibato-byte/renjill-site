# 動く 3D のレンとジル（guide3d.js）のくわしい理由

guide3d.js は 48KB までと決めているので、長い説明はここに置く。コードの中の「（→ NOTES）」は、このファイル（docs/GUIDE3D-NOTES.md）を指す。

- **3D の画面はページの中に置き、描いたときのスクロール位置へ動かす**：3D の画面はページの中に置き、描いたときのスクロール位置へ動かす（素早いスライドでもページとずれない。2026-11-16）
- **たれ耳：付け根（上）は動かず、先ほど大きく動く。**：たれ耳：付け根（上）は動かず、先ほど大きく動く。動かすのは耳の形のところだけ（前は耳のあたりの縦の帯ごと動かしていて、レンは背中まで動き、髪の毛のように見えた。2026-11-16）
- **頭と耳をひとかたまりで**：頭と耳をひとかたまりで（前は高さの帯で分けていて、体の前に垂れたレンの耳が途中でちぎれ、ぎざぎざに見えた。2026-11-16）
- **うさぎ跳び（2026-11-16 オーナー：「移**：うさぎ跳び（2026-11-16 オーナー：「移動もうさぎの走り方を忠実に」）。けると前足は前へ・後ろ足は後ろへのびて体が長くなり、着くと足を体の下に集めて背中（お尻の側）が丸く上がる
- **横を向くとき：体はあまり回さず、頭（上のほう）を**：横を向くとき：体はあまり回さず、頭（上のほう）を大きく回す。板を回すと横幅が細って平べったく見えるので、そのぶん幅を戻す（2026-11-16 オーナー「横を向いたレンが平べったい」）
- **幅を戻す割り算は、角度が大きいと絵を引きのばして壊すので、角度は必ず ±0.6 までに限る**：幅を戻す割り算は、角度が大きいと絵を引きのばして壊すので、角度は必ず ±0.6 までに限る。押したときに 1 回転させる案は、真横を向いた瞬間に板の薄さが見えておかしいので、やめた（かわりに、高く跳ねて体を左右に振る）
- **2 人の間：ジルの頭がレンの体に食いこまないよう**：2 人の間：ジルの頭がレンの体に食いこまないよう広げた（0.36・0.80 → 0.31・0.87。2026-11-16）。とても細い画面（360 未満）は、見出しに重なるので元の間のまま
- **ここを押したら 2 人に当たるか**：ここを押したら 2 人に当たるか（最初の画面の「ハンコ」が、2 人の上に押されないように index.html から使う）
- **居眠り：レンは着いたらすぐ目を閉じ（にっこりしな**：居眠り：レンは着いたらすぐ目を閉じ（にっこりしない）、目を閉じてから Zz を出す（2026-11-16 オーナー「Zz が出るのに、寝るのが遅い。合っていない」）
- **体の中の動き（2026-11-16。調べた動きは**：体の中の動き（2026-11-16。調べた動きは docs/RABBIT-MOTION-2026-11-16.md）
- **頭の向きを変えた時の耳のゆれ**：頭の向きを変えた時の耳のゆれ（26 では大きすぎ、耳先が背中・お尻の側へはみ出した。2026-11-17 オーナー指摘）
- **たれ耳は重く、頭の横にそってゆれるだけ**：たれ耳は重く、頭の横にそってゆれるだけ：横への振れは ±0.1 まで（それ以上は耳先が体の外へ出て、背中から生えたように見えた）
- **向き：移動中は進む方向へ。止まっているときは、P**：向き：移動中は進む方向へ。止まっているときは、PC はカーソルのほう、スマホはゆっくり見回す。ときどき相手のほうを見る
- **カーソルを目で追う**：カーソルを目で追う。すぐ近く（体の上）では向きを変えすぎない：前は、体の上で少し動かすだけで頭が左右に大きくふれ、となりの子に食いこんだ
- **向きは、ばねで追う**：向きは、ばねで追う（前は一定の割合で近づけていて、動き出しと止まり方が機械のようだった）。行きすぎないくらいの強さ
- **場所が画面に止まっている間は 3D の画面も固定**：場所が画面に止まっている間は 3D の画面も固定（ページの中のままだと 1 コマ遅れて戻り、ぐらついた。11-17）
- **手前（z>0）に来ると遠近で外へずれる。着いてい**：手前（z>0）に来ると遠近で外へずれる。着いているときは足の位置が HTML とずれないよう打ち消す（画面の端からはみ出さない）
- **ページの終わり**：ページの終わり（フッターの下）を測る。画面の高さで測ると、この画面自身の高さが入って縮まなくなる
- **2026-11-16**：2026-11-16：512 では手足がつぶれたので 2 倍（絵の割合は前と同じ）
- **寝る姿勢（2〜3 段目）の大きさの倍**：寝る姿勢（2〜3 段目）の大きさの倍率＝img/g3d/poses.json（検査 57）
- **板の分割数（2026-11-16：耳**：板の分割数（2026-11-16：耳の形のとおりに動かすので、40 から細かく）
- **うさぎ跳び：x＝のび、y＝ちぢみ（背**：うさぎ跳び：x＝のび、y＝ちぢみ（背中を丸める）、z＝進む向き（-1・0・1）、w＝前足の着地
- **fx：場所の箱の中での足の位置（横）**：fx：場所の箱の中での足の位置（横）／k：箱の高さに対する背の高さ／dz：手前に出す量
- **奥行きのある牧草**：奥行きのある牧草（最初の画面だけ。カメラに近いほど大きく、ぼけて、速く流れる）
- **最初の画面だけ**：最初の画面だけ：スクロールすると 2 人がカメラのほうへ近づく（奥行きのあるスクロール）
- **うさぎの跳びは低く長い**：うさぎの跳びは低く長い（前は 0.42：高く上がりすぎて、ボールがはねるように見えた）
- **空中は体が長く低い・着いた時は背中が丸く高い**：空中は体が長く低い・着いた時は背中が丸く高い（前は逆に、空中で縦にのびていた）
- **うさぎ跳びの形**：うさぎ跳びの形：のびは、けった直後がいちばん大きい。着く少し前から前足を下ろし、前足 → 後ろ足の順に着く
- **場所が画面に止まっている所**：場所が画面に止まっている所（ある一日）では歩かない（ジルがぐらついた。11-17）
- **なでる：カーソルを乗せると、にっこり**：なでる：カーソルを乗せると、にっこりして少し沈む。乗せた瞬間に 1 回だけ跳ねる
- **光：登場のときは左から右へさっと流れ**：光：登場のときは左から右へさっと流れる。PC はカーソルの方向から、スマホはページの進みぐあいでゆっくり回る
- **場所の色に合わせる**：場所の色に合わせる：紺の所は少し青く、こげ茶の所は少し暖かく。暗い所では、ふちを光らせる
- **絵が別の場所**：絵が別の場所（CDN）から配られても読めるように。同じ場所なら何も変わらない
